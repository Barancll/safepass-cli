{% comment %} Lokki, the SafePass mascot: a small padlock with arms and legs that gives the security tips. Usage: include partials/mascot.html with uid="gen" (uid keeps the gradient ids unique when several are on one page); optional lokki_class adds classes, mood sets the starting expression (idle, happy, thinking, worried, sleepy, awake, typing, surprised, sad, cheer, shy), size sets width/height attributes (needed when Lokki sits inside another SVG, where CSS sizes don't apply). Expressions are switched with the data-mood attribute; motion lives in components/mascot.css. {% endcomment %}
